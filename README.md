# 💻 Exercícios de Aprendizado em C#

Bem-vindo ao meu repositório de estudos em **C#**! 🚀

Este espaço foi criado para documentar minha jornada de aprendizado na linguagem C#, reunindo exercícios práticos e exemplos de código desenvolvidos durante meus estudos.

O objetivo é evoluir gradualmente, desde os fundamentos da programação, aplicando boas práticas de desenvolvimento e consolidando o conhecimento por meio da prática.

## 🎯 Objetivos

- Aprender e consolidar os fundamentos da linguagem C#.
- Desenvolver o raciocínio lógico e a capacidade de resolver problemas.
- Conhecer os principais recursos do ecossistema .NET.
- Aplicar boas práticas de escrita, organização e manutenção de código.
- Acompanhar e documentar minha evolução como desenvolvedor.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** C#
- **Plataforma:** .NET
- **IDE:** Visual Studio / Visual Studio Code
- **Versionamento:** Git
- **Repositório:** GitHub

## ▶️ Como Executar os Exercícios

**1. Clone o repositório:**

```bash
git clone https://github.com/MatheusdeCastroViana/exercicios-aprendizado-em-csharp.git
```

**2. Acesse o diretório:**

```bash
cd exercicios-aprendizado-em-csharp
```

**3. Entre na pasta de um exercício que contenha um projeto .NET (`.csproj`).**

**4. Execute o projeto:**

```bash
dotnet run
```

É necessário ter o **.NET SDK** instalado. Alguns exercícios poderão exigir configurações específicas, documentadas em seus respectivos diretórios.
